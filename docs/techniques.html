Techniques · Family Sudoku

The moves the coach teaches, on real boards

Every position below was taken from a board the app generated, at the moment its engine chose that technique. Every empty square shows its pencil marks at that moment, so each move can be checked against the picture. The tinted squares are the pattern, struck-out digits are the candidates it removes, and the quoted line is what the coach says when you tap Explain.

Tier 1 and 2 · Singles

Easy and Medium boards need nothing else.

Tier 1 and 2

Naked single

One square, one candidate. Its row, column and box already hold the other eight digits, so the remaining digit is written in. The coach calls this a naked single because the answer is sitting there in plain view once the notes are in.

“At Row 2, Column 9, every other digit already appears in its row, column or 3×3 box, leaving 6 as the only candidate.”

Tier 1 and 2

Hidden single

Look at one digit and one unit. If that digit has only one square left in the unit where it can go, it goes there, however many other candidates that square shows. The shaded unit is the one being scanned; the small digits mark where the digit could still sit.

“Scan Row 2 for the digit 2: Row 2, Column 8 is the only square in Row 2 where 2 can still go.”

Tier 3 · Pairs, triples and lines

Hard boards need some of these. This is where pencil notes stop being optional.

Tier 3

Naked pair

Two squares in a unit show exactly the same two candidates. Between them they must hold both digits, so those digits come out of every other square in the unit. You do not yet learn which square gets which.

“In Column 1, Row 3, Column 1 and Row 9, Column 1 can only be {1, 9}. Those two digits are locked there, so 1 and 9 can be removed from every other square in Column 1.”

Tier 3

Hidden pair

Two digits that can each go in only the same two squares of a unit. Those squares must be those two digits, so their other candidates are struck out.

“In Row 1, the digits 2 and 5 both fit only in Row 1, Column 2 and Row 1, Column 8. Those squares must be 2 and 5, so their other pencil marks can go.”

Tier 3

Naked triple

Three squares whose candidates, put together, are only three digits. Each square may show two or three of them. The three digits leave every other square in the unit.

“In Column 7, three squares (Row 3, Column 7; Row 6, Column 7; Row 7, Column 7) share only the digits {1, 2, 3}. Those three digits are locked in those squares, so they can be removed from the rest of Column 7.”

Tier 3

Hidden triple

Three digits confined to the same three squares of a unit. Those squares are spoken for, so anything else pencilled in them goes.

“In Box 6, the digits 1, 2, 4 fit only in Row 4, Column 7; Row 4, Column 9; Row 5, Column 7. Those three squares must hold those three digits, so their other pencil marks can go.”

Tier 3

Pointing pair

Inside a box, a digit has only two or three possible squares and they all lie on one line. The box must put the digit on that line, so it cannot appear elsewhere on the line outside the box.

“Inside Box 3, the digit 6 can only sit in Row 3. Since Box 3 must hold a 6 there, 6 cannot appear anywhere else in Row 3.”

Tier 3

Box-line reduction

The mirror image. Along a row or column, a digit fits only inside one box. The line will use up that box's copy, so the digit leaves the rest of the box.

“In Row 9, the digit 3 can only go inside Box 7. That uses up the 3 for Box 7, so 3 can be removed from the rest of that box.”

Tier 4 · Wings and fish

Master boards need these.

Tier 4

X-Wing

Pick one digit. Two rows each have exactly two places for it, and the places line up in the same two columns, forming a rectangle. Whichever diagonal the digit takes, both columns are served by those rows, so the digit leaves every other square in those columns. Rows and columns can be swapped.

“Columns 3, 7 each have exactly two places for 2, lined up in Rows 3, 9. Whichever diagonal holds the 2s, both of those rows are used up, so 2 can be removed from their other squares.”

Tier 4

Swordfish

The X-Wing with three rows and three columns. Harder to see on a full board, identical logic.

“In Columns 4, 5, 8, every place for 8 falls in Rows 2, 4, 8. Three columns need three 8s, which uses up those three rows, so 8 can be removed from their other squares.”

Tier 4

Y-Wing

Three squares with two candidates each. A pivot {A, B} sees one square {A, C} and another {B, C}. Whatever the pivot is, one of the others must be C, so any square seeing both of them cannot be C.

“Row 7, Column 6 is {1, 2}. It sees Row 7, Column 7 = {1, 9} and Row 9, Column 5 = {2, 9}. Whether the pivot is 1 or 2, one of those two squares must be 9, so any square that sees both of them cannot be 9.”

Tier 5 · Chains and uniqueness

Grandmaster boards need these.

Tier 5

XY-Chain

A longer Y-Wing: a string of two-candidate squares, each sharing a digit with the next, with the same digit at both ends. Whichever way the first square falls, one end becomes that digit, so squares that see both ends cannot be it. The first technique where you follow "if this, then that".

“Follow the chain Row 2, Column 1 {1,9} → Row 2, Column 6 {1,9} → Row 3, Column 4 {1,9} → Row 6, Column 4 {1,9}. Whichever way the first square goes, one end of the chain is 1, so 1 cannot sit in any square that sees both ends.”

Tier 5

Unique rectangle

The pencil marks shown already reflect earlier steps on this board (a pair or a pointing move removed some candidates). Check the move against the marks as drawn.

Four squares in a rectangle across two boxes, three of them exactly {A, B}. If the fourth could also be A or B the puzzle would have two solutions, which a proper puzzle never has. So the fourth is neither. It uses the promise of uniqueness as a tool.

“Row 2, Column 3; Row 2, Column 5; Row 3, Column 3 and Row 2, Column 3 form a rectangle across two boxes, and three corners are exactly {3, 8}. If Row 2, Column 3 were 3 or 8 too, the four could be swapped for a second solution, which a proper puzzle never has, so 3 and 8 come out of that corner.”

Beyond the coach · what Extreme demands

The engine stops here, and so do the hints. Extreme boards are proven to have one solution, then left to you.

Beyond

Almost locked sets

A group of squares with one more candidate than squares. Any single elimination collapses it into a locked set, which makes it a strong link in a chain. Powerful, and hard to spot without practice.

Beyond

Forcing chains

Take a square, try each candidate in turn, and follow the consequences through the board. Where every branch agrees on something, that thing is true regardless of which branch is right.

Beyond

Nishio and trial

Assume a digit and push until the board breaks or completes. Purists frown, but at the top it is often the only road. The What-if bookmark exists for exactly this: try a path in teal, rewind if it collapses.
